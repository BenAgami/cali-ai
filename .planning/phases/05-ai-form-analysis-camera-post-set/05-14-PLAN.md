    scoring:
    - aggregateDimension([90, 80, 70]) = round(0.85 x 80 + 0.15 x 70) = 79; NaN entries ignored; all NaN -> null
    - computeOverall({ ROM: 80, CORE: 60, SYMMETRY: null }, weights ROM 0.5 CORE 0.5 SYMMETRY 0, assessed SYM false) = 70
    - pull_up weights 0.5/0.1/0.4 with ROM 90, CORE 50, SYMMETRY 80 -> round(0.5x90 + 0.1x50 + 0.4x80) = 82

    selectFindings:
    - rep tag on 2 of 5 reps (40%) -> detected (ceil(0.4 x 5) = 2); on 1 of 5 -> not detected
    - set severity = max affected-rep severity; rank = weight (LOW 1, MEDIUM 2, HIGH 3) x affectedFraction
    - three detected tags [ROM HIGH 0.6, ROM MEDIUM 1.0, CORE MEDIUM 0.4] -> selected = [ROM MEDIUM 1.0 (rank 2.0), CORE MEDIUM 0.4 (0.8)] — the second ROM tag is skipped because CORE has one
    - only ROM tags [A rank 2, B rank 1.2, C rank 0.6] -> [A, B]
    - ties broken by dimension order ROM, CORE, SYMMETRY then tag code
    - FATIGUE_DROP set tag included as a detected finding with its repNumbers
    - no detected tags -> []
    - positives: GOOD/EXCELLENT assessed dimensions first, then FULL_RANGE when no fullRangeTags fired on any rep, CONSISTENT_DEPTH when std(depthFeature) < depthStdMax, STEADY_TEMPO when the rushedTag never fired and duration CV < 0.25; at most 2 of these, then always "You finished N reps." last; all-Poor set -> exactly the fallback
  </behavior>
