    `AnalysisTrackerContext.tsx`:
    ```ts
    export type TrackedAnalysis = { sessionId: number; jobId: string; workoutId: number | null; setNumber: number | null; exerciseCode: string; exerciseDisplayName: string };
    export type AnalysisToastState = { sessionId: number; title: string; body: string };
    type AnalysisTrackerValue = {
      tracked: TrackedAnalysis[];
      statusBySession: Record<number, AnalysisStatusEvent | undefined>;
      unseenSessionIds: ReadonlySet<number>;
      track: (item: TrackedAnalysis) => void;            // replaces an entry with the same sessionId
      retry: (sessionId: number) => Promise<void>;        // sessionsApi.retryAnalysis -> replace jobId -> clears status
      markSeen: (sessionId: number) => void;
      entriesForWorkout: (workoutId: number) => TrackedAnalysis[];
      toast: AnalysisToastState | null;
      dismissToast: () => void;
    };
    export const AnalysisTrackerProvider: React.FC<{ children: React.ReactNode }>;
    export const useAnalysisTracker: () => AnalysisTrackerValue; // throws if used outside the provider
    ```
    The provider renders `children` plus one internal `AnalysisWatcher` (returns null) per tracked entry, keyed by `${sessionId}:${jobId}`; each calls `useAnalysisStatus(sessionId, jobId)` and reports `event` changes up through a callback in `useEffect`. On a COMPLETED event: `queryClient.invalidateQueries({ queryKey: analysisKeys.session(sessionId) })` and, when workoutId is set, `analysisKeys.recordedSets(workoutId)`; add sessionId to `unseenSessionIds`; set `toast = { sessionId, title: "Feedback ready", body: setNumber ? \`${exerciseDisplayName} - set ${setNumber}\` : exerciseDisplayName }`. On FAILED: invalidate recordedSets only (no toast; D-11 is inline). On mount, re-hydrate once: `sessionsApi.listByStatus("PROCESSING")` and `track` each item with a non-null `bullmqJobId` (exercise code/displayName from `item.exercise`); log nothing on failure (silent retry next mount). Use `useCallback`/`useMemo` for the context value.
    `AnalysisToast.tsx`: reads `toast` from the tracker; renders nothing when null; otherwise an absolutely positioned banner at the top (safe-area inset from `useSafeAreaInsets`), Reanimated `entering={SlideInUp}` / `exiting={SlideOutUp}`, `accessibilityLiveRegion="polite"`, theme `colors.surface` background and `colors.text` text, title + body + a "View feedback" button (`accessibilityRole="button"`) that calls `markSeen(sessionId)`, `dismissToast()`, then `router.push({ pathname: "/analysis-result", params: { sessionId: String(sessionId) } })`, and a close control. Auto-dismiss after 6000 ms (clear the timer on change/unmount). No hard-coded hex colours except via `baseColors`.
