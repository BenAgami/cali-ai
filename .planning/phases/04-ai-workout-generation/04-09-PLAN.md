`run.ts`: for each model in `[env.llm.primaryModel (effort env.llm.primaryEffort), env.llm.fallbackModel (effort env.llm.fallbackEffort)]` × goal × level: one call (no ladder; measures raw model quality), timeout = that model's env timeout, `AbortSignal.timeout(timeoutMs)`. Record per call: model, goal, level, `latencyMs` (performance.now), `inputTokens`, `outputTokens`, `schemaValid` (call returned a plan), `llmErrorCode` (if LlmError), `catalogValid` + `issues` (validateGeneratedPlan), `restPresent` (every restSecs >= 30), `noteSet` (note non-null). Per (model, goal): `levelDiffers` = advanced volume > beginner volume, where volume = Σ sets × (reps ?? durationSecs / 3). Print a summary table per model via `process.stdout.write` (pass rate for each criterion, p50/max latency, mean tokens), and expect the handstand and knee goals to have `noteSet`. Write full JSON to `apps/api/scripts/workout-eval/results/<ISO timestamp>.json` (mkdir recursive). Exit code 0 even when criteria fail (it is a report).
`package.json` scripts: `"eval:workouts": "tsx scripts/workout-eval/run.ts"` (Knip treats it as an entry). `tsconfig.json` include: add `"scripts/**/*.ts"` so the eval is type-checked and linted. `.gitignore`: add `apps/api/scripts/workout-eval/results/`. Not part of CI or the vitest projects.
